# نظام الحضور الذكي — دراسات فلسطينية

## التشغيل المحلي
1. `npm install`
2. `cp .env.example .env` وضع في `DATABASE_URL` رابط PostgreSQL (محلي أو Supabase). للتجربة المحلية اجعل `NODE_ENV=development` فيُطبع رمز التفعيل في الطرفية بدل البريد. الجداول تُنشأ تلقائيًا إن لم تكن موجودة.
3. `npm start` ثم افتح http://localhost:3000/login واضغط "تفعيل الحساب".
