# نظام الحضور الذكي — دراسات فلسطينية

## التشغيل المحلي
1. `npm install`
2. `cp .env.example .env` (للتجربة المحلية اجعل `NODE_ENV=development` فيُطبع رمز التفعيل في الطرفية بدل البريد، واترك متغيرات Turso فارغة فتُحفظ البيانات في ملف محلي)
3. `npm start` ثم افتح http://localhost:3000/login واضغط "تفعيل الحساب".

## الحسابات
يُنشأ حساب الدكتور (`DOCTOR_EMAIL`) والحسابات في `EXTRA_ALLOWED_EMAILS` تلقائيًا عند أول تشغيل، وبعدها تُدار من صفحة **الحسابات** في لوحة التحكم.
كل الحسابات محفوظة في قاعدة البيانات وتدخل لوحة الدكتور نفسها. التفعيل مرة واحدة برمز على البريد، ثم الدخول بالإيميل وكلمة المرور من أي جهاز (الجلسة 30 يومًا).
الخطوات الكاملة للنشر المجاني (Render + Turso) في DEPLOY.md
